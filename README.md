# Copenothing Frontend

## Description / Описание
This is the frontend of the Copenothing project, built with Next.js and TypeScript. It provides the user interface for the application.
Этот проект является фронтендом Copenothing, построенным на Next.js и TypeScript. Он предоставляет пользовательский интерфейс для приложения.

## Installation / Установка

1. Clone the repository / Склонируйте репозиторий:
 ```bash
 git clone <repository-url>
 cd frontend
 ```

2. Install dependencies / Установите зависимости:
 ```bash
 npm install
 ```

3. Create a `.env` file based on the provided `.env.example` / Создайте файл `.env` на основе предоставленного `.env.example`.

## Running the Application / Запуск приложения

- For development / Для разработки:
```bash
npm run dev
```

- For production / Для продакшена:
```bash
npm run build
npm run start
```

## Testing / Тестирование

To run linting, use / Чтобы запустить линтинг, используйте:
```bash
npm run lint
```
